# Report skeleton

1. Executive snapshot — short, honest, non-technical
2. Scope, envs, tools, limits — what could not be seen
3. Role-by-role scorecard — one line each for the roles that applied
4. Findings table — ID, title, severity, layer, owner role, fixable, effort
5. Deep-dives — fields A-J
6. Quick wins — this week
7. Structural work — this month
8. Test / cert plan
9. Open questions
