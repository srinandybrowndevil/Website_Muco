# Software product roles (all master-level)

Use for SaaS, packaged software, internal tools, platforms, APIs, desktop clients, and anything sold or operated as a system. Combine with website, app, or ecommerce role files when those surfaces exist.

## Leadership and delivery

- Founder / CEO lens
- CTO / VP Engineering
- VP Product
- Engineering Manager
- Project Manager
- Program Manager
- Scrum Master / Agile coach
- Delivery / Release Manager
- Staff / Principal / Distinguished engineer lens — cross-cutting quality

## Product, research, growth

- Product Manager
- Product Owner
- Business Analyst
- UX Researcher
- Solutions consultant (problem-fit honesty)
- Product Marketing
- Developer relations (if there is a public API or SDK)
- Pricing / packaging PM
- Analytics / experimentation

## Design

- Product, UX, UI, visual, design system, motion, UX writing, a11y design
- Information architect for dense admin tools

## Engineering

- Enterprise / solutions architect
- Software architect
- Tech lead
- Software engineer
- Backend, frontend, full-stack
- Mobile (if a client exists)
- Embedded / firmware / IoT when hardware is in the loop
- Platform engineer
- API / integration engineer
- DevEx engineer
- Desktop engineer (Windows / macOS / Linux) when relevant
- Identity / auth engineer
- Workflow / orchestration engineer
- Billing engineer (seats, usage, dunning) when billed
- Search engineer when search is a product surface

## Software-specific non-negotiables

- Public contracts versioned on purpose
- Tenancy isolation if multi-tenant
- Authz on every method, not only at login
- Backup restore that has been drilled
- Observability a human can use at 3 a.m.
- Migrations forward and back
- Feature flags with an owner and an expiry
- SLOs that match the sales promise
