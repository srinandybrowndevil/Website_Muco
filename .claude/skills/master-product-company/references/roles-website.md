# Website and web-app roles (all master-level)

Use every role below on a website or web app. Depth scales with the job. Names stay on the review board even when silent.

## Leadership and delivery

- Founder / CEO lens — promise on first screen, what not to build, brand risk
- CTO / VP Engineering — stack bet, build vs buy, debt policy, quality system
- VP Product — outcome over output, kill criteria
- Engineering Manager — scope, sequencing, honest estimates
- Project Manager — critical path, status without theater
- Program Manager — multi-workstream contracts
- Scrum Master — impediments, no cargo-cult ritual
- Release Manager — go/no-go, freeze, rollback owner, stakeholder comms

## Product, research, growth

- Product Manager — JTBD, PRD, acceptance, launch metric
- Product Owner — backlog order, definition of done
- Business Analyst — as-is / to-be, rule traceability
- UX Researcher — test script, what claims need evidence
- Growth — activation, retention, experiment guardrails
- Product Marketing — positioning, launch narrative
- SEO specialist — intent, crawl/index, internals, thin/duplicate, CWV hygiene
- Analytics — event taxonomy, funnel definitions, no vanity-only charts
- Content strategist — IA of pages, sitemap of meaning

## Design and brand

- Product designer — end-to-end flows
- UX designer — task success, forms, nav, cognitive load
- UI designer — type, space, color, density, breakpoints
- Visual / brand designer — logo, brand system, marketing surfaces
- Design-systems designer — tokens, variants, breaking-change rules
- Motion designer — duration, easing, reduced-motion fallback
- UX writer — labels, placeholders, errors a human can use
- Accessibility designer — inclusive pattern before retrofit

## Engineering

- Software architect — boundaries, quality attributes, ADRs
- Tech lead — slice design, review the risky parts
- Frontend engineer — implementation fidelity, client state, resilient UI
- Backend engineer — APIs, jobs, authz, idempotency, integrity
- Full-stack engineer — pixel to query to deploy without dropping a side
- Platform / DevEx — paved road, local boot in minutes
- API / integration engineer — contracts, webhooks, sloppy-client resilience
- CMS / content-platform engineer — preview, publish, preview-prod drift
- Email / notification engineer — templates, deliverability, unsubscribe
- Search engineer — relevance, ranking hygiene, latency (if search exists)

## Data

- Data engineer — pipelines, late data, quality checks
- Analytics engineer — trusted metric layer
- DBA / database engineer — schema, indexes, backup restore drills

## Cloud and ops

- DevOps — CI/CD, env promotion local → dev → test → staging → pre-prod → prod/cert
- SRE — SLIs/SLOs, toil, incident command, error budgets
- Cloud / infra — IAM, DNS, TLS, CDN, WAF, cost
- Build / release — pinned artifacts, SBOM, true changelogs
- IT / corporate eng — SSO, least privilege on admin tools

## Quality and safety

- QA / test engineer — certify against a stated bar
- SDET — right-layer automation, no flaky palace
- Exploratory tester — clumsy, hostile, first-time, impatient users
- Performance engineer — CWV, budgets, waterfall, what dies first
- AppSec — threat model, OWASP, secrets, supply chain
- Privacy engineer — consent that actually blocks, PII in URLs/logs
- Accessibility engineer — WCAG 2.2 AA default unless specified
- Resilience engineer — dependency down, prove fallback

## Customer

- Technical writer — docs a new person can use
- Support engineer — reproduce from a ticket, known-error db
- Solutions / implementation — time-to-first-value
- Webmaster / site owner ops — redirects, domain, uptime comms

## Website-specific non-negotiables

- Every nav, footer, in-page anchor, modal, tab, pagination
- 404 / 403 / 500 / maintenance pages
- Redirect chains, www vs apex, http vs https, trailing slash
- Title, meta, canonical, robots, sitemap, OG, structured data
- Forms, autofill, validation, file upload
- Tab order, focus ring, skip link
- 320 through 1920, zoom 200%, slow net, blocked third-party JS
