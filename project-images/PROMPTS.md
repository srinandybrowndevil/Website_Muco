# Portfolio image provenance

Created with the built-in imagegen tool. These are AI-generated project illustrations, not captures of deployed products or actual client product photography. Originals are stored in this folder; optimized responsive variants are in `assets/projects`. Run `python build_project_images.py` and `python build.py` after replacing an original.
